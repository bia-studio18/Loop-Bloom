# Loop & Bloom

Cute handmade accessories store — Scrunchies, Bracelets & Mini Bags.

**Theme:** Soft Peach + Pink  
**Instagram:** [@loop_bloom.pk](https://www.instagram.com/loop_bloom.pk/)

---

### Features

- Beautiful peach & pink girly design
- Home page + Shop page
- Product detail pages
- Shopping Cart (shortlist items)
- **Order on Instagram** button (copies order details automatically)
- **Admin Panel** (password protected)
  - Add / Edit / Delete products
  - Update product images via URL
  - Changes saved in browser (localStorage)

---

### How to Use

1. Open `index.html` in any browser
2. Browse products and add to cart
3. Go to Cart → Click **Order on Instagram**
4. Order details are copied → Paste in Instagram DM

### Admin Panel

1. Open `admin.html`
2. Password: `loopbloom123`
3. Add your real products with image links

**Tip for images:**  
Upload photos to [Imgur](https://imgur.com) or Google Drive → Copy the direct image link → Paste in Admin.
